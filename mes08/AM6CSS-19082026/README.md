# Atividade do Material 6 de CSS 

## Subatividade A

Crie um layout de página utilizando o atributo ***display: grid*** 

### REQUISITOS:

> Deve conter um **Header**, **Sidebar**, **Main**, **Footer**;
> Use o atributo ***grid-template-areas***;
> Cada área deve diferir nas cores;
> Teve ter uma altura mínima de 400px.

## Subatividade B

Nessa subatividade crie algumas transições: 

### Requisitos

> - Crie um botão com transição - exemplo: mudar de cor ao pairar o mouse em cima. Utilizando o atributo ***hover***;
> - Crie também uma animação de "quicar" -  pulsar.
