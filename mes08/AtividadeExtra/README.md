# Atividade Extra

Crie uma página com os seguintes requisitos:

## REQUISITOS:
> - Deve haver um título principal;
> - Devem haver **oito** cards com imagens - podem ser utilizados emojis, imagens por link, só não esqueça dos alt das imagens;
> - A tag pai dos cartões devem utilizar o atributo display no valor ***flex*** para serem responsivas.
>
>Exemplo:
>> selector {
>>      display: flex
>>      flex-wrap: wrap
>>      justify-a: center
>>      gap: 20px
>>
>> }
>>
>
> Cada cartão deve haver as seguintes especifícações:
> - Os cartões devem possuir uma largura de 250px;
> - As imagens dentro do cartão devem possuir uma altura de 200px;
> - As imagens dentro do cartão devem possuir um atributo **object-fit** no valor de ***cover***;
> - As bordas do cartão devem ser **arredondadas**;
> - Os cartãos deve possuir **sombra**;
> - Os cartãos deve possuir a pseudo-class **hover** para simular um zoom.

#### Observação:

> - A página deve ser responsiva. Na tela pequena deve haver apenas um cartão por linha.
